# DFo 1-3: Tipos de Modelo de Banco de Dados

## Exercício 1 — Identificação dos Modelos de Banco de Dados

### Respostas

**a) Modelo Hierárquico**

Representa os dados em uma estrutura semelhante a uma árvore, organizada em níveis de relacionamento entre registros, com relações de pai e filho.

**b) Modelo de Dados Hierárquico**

Também utiliza uma estrutura hierárquica em forma de árvore, na qual os dados são organizados em níveis e os registros possuem relações de pai e filho.

**c) Modelo de Banco de Dados Orientado a Objetos (MBDOO)**

Organiza os dados como objetos, permitindo representar atributos e comportamentos de forma semelhante à programação orientada a objetos.

**d) Modelo Relacional**

Organiza os dados em tabelas compostas por linhas e colunas, utilizando relacionamentos entre as tabelas por meio de chaves, como chaves primárias e estrangeiras.
