# Resoluções — Oracle Database Foundations

Resoluções das atividades práticas realizadas durante o curso **Oracle Database Foundations**, da **Oracle Academy**.

Este repositório foi criado com o objetivo de registrar e organizar o aprendizado adquirido durante o curso, reunindo as atividades e soluções desenvolvidas pelo autor ao longo dos estudos.

## Conteúdo

O repositório reúne conteúdos produzidos pelo próprio autor, incluindo:

- Resoluções das atividades práticas;
- Scripts SQL desenvolvidos durante os exercícios;
- Modelos de dados e diagramas;
- Anotações e explicações próprias;
- Outros materiais desenvolvidos como parte do processo de aprendizagem.
